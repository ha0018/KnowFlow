# quality-v1

100 条自编合成语料题，主标签比例 70/15/10/5；调参 40 条，保留 60 条，分别为 28/6/4/2 与 42/9/6/3。校验值见 `quality-v1.sha256`。

`gold` 使用资料 key 和原文 quote；`seed_quality` 在实际发布后将其映射为文档版本 SHA-256、解析块与字符范围。没有使用检索结果生成标签。所有金额、编号和组织样本均为演示数据。

源文件、分集和标签按版本固定。修改时应创建新版本，不覆盖既有已测保留集。实现细节、局限、命令和指标见 [S3 说明](../retrieval-quality.md)。
