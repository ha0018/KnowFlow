# S5 交付与完整验收实施计划

基线：`de8bb5f`（S4 已合入 main）。实现分支：`codex/s5-delivery`。所有验收结果以实际报告为准。

| 顺序 | 实施内容 | 验证与退出条件 | 状态 |
| --- | --- | --- | --- |
| 1 | 成员创建/停用、角色分配与编辑、知识库及文档 ACL 界面；补齐读取授权和主体选择接口 | 管理员浏览器闭环；普通用户/跨租户拒绝，撤权立即生效且有审计 | 已交付，双会话浏览器及授权矩阵通过 |
| 2 | 解析子进程期限、Linux CPU/内存/输出限制；孤儿对象扫描与有保留窗口的清理、过期凭据和悬挂工作回收 | 实际超时/资源错误终止，保留旧构建；默认 dry-run，不删除引用中的文件 | 已交付，Linux 资源限制和清理保护通过 |
| 3 | PostgreSQL + 私有对象联合备份、完整校验及隔离恢复演练 | 暂停写入的一致快照，恢复到新数据库/空对象空间，核对行数/原文件 SHA-256 与引用 | 已交付，93 文件、35 表摘要一致，恢复后十组检查通过 |
| 4 | A01–A15 逐项验收、安全/入库/幂等/版本/流式/追踪矩阵、API/检索负载、重复故障演练 | 原始报告保留失败和分母；环境、配置、代码版本可追溯 | 已测量并归档；A09/A10 延迟未达标，真实模型/人工项待验收 |

真实供应商、人工语义复核与固定区域模型性能仍依赖外部配置，保持待验收；演示模型和受控 HTTP 替身只用于验证工程行为。S5 不会将这些目标数字登记为实测成果。备份恢复只向新目标写入；本机已有数据只做备份和 dry-run，清理删除在临时测试/CI 环境验收。

交付结果及处理决定见 [S5 报告](benchmarks/delivery-2026-11-13.md) 和 [A01–A15 状态](acceptance.md)。S5 工程交付完成不等于全部性能/语义目标通过，项目仍保持开发演示版定位。
