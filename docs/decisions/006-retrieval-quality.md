# ADR 006：冻结原文证据并保留精确对照

日期：2026-11-10。

文档级命中不足以判断答案证据是否被召回。S3 使用版本哈希、解析块和字符范围标注 gold，MRR 保留片段位次，不先去重文档；文档召回、证据覆盖、引用标记有效性与人工语义支撑分别报告。

100 条自编题固定为 40 调参/60 保留。Push CI 运行调参集，保留集通过显式 workflow_dispatch 选择；没有真实模型或人工复核时不宣布语义质量验收通过。错误样本、未知 usage 和未复核状态都保留。

增强适配器只接收当前授权输入，候选重排后重新校验权限。改写与重排使用现有原子额度控制；本地规则/词项重排清楚标识，不包装成真实模型。外部协议替身用于测试传输和边界。

HNSW 是可选查询模式，默认精确 cosine。用真实授权 queryset、两种规模和选择率做单连接合成向量诊断，保存执行计划并核对实际索引。近似检索在强过滤下可能损失邻居，不能仅凭返回满 K 或一次耗时就默认开启。正式业务负载验收另测。
