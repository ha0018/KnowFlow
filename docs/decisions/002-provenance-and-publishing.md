# ADR 002：不可变来源与原子发布

状态：采用。

稳定 Document 指向不可变文件版本的 IndexBuild。构建快照包含解析、切片、分词、Embedding profile；相同版本和 pipeline hash 复用。任务租约领取时递增 fence token，各阶段写入和发布校验 token、任务状态、当前权限、desired build 与删除状态。

新构建完整性通过后短事务切换 active build，失败保持旧版。旧来源保留给历史引用，权限由当前策略决定。触发器固定文件内容标识与来源归属，不能把历史引用重新指向新文档。

代价：旧版本、解析产物和引用占用存储；自动保留期/清理尚未实现，软删除先负责即时退出授权范围。
