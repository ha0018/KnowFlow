# ADR 003：检索和历史读取时检查当前授权

状态：采用。

用户/租户由认证确定。检索 SQL 的候选范围已经包含 KB 和文档授权、删除状态、active build 与 Embedding profile；从未先读取跨租户内容再过滤。历史引用保留原版本快照，但读取时再次检查来源文档是否可读；任一来源失权，整段 assistant 正文隐藏。

权限变更递增租户 ACL epoch。流式运行开始、模型请求前和输出期间检查 epoch；发生变化保守终止。当前不向模型重放历史，避免把旧答案当作当前证据。

代价：一个无关文档授权变化也会终止该租户正在运行的回答。后续可以在保留安全属性的前提下缩小失效范围。
