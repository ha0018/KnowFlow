# ADR 005：分开记录预算、供应商用量和估算费用

状态：采用。供应商实测尚待配置。

生成和向量请求使用独立服务、认证及模型配置。旧 AI_* 配置只在未指定新 endpoint 时回退，避免把原供应商的 key 转发到其他地址。状态接口、配置对象 repr、协议异常和探测报告均排除 key 和完整地址。

本地 UTF-8 字节估算用于准入、上下文裁剪和预留，供应商报告用于实际 Token 结算。估算偏保守，有助于在未知 tokenizer 的兼容服务上限制输入，但不应称作精确计费。没有有效 usage 的已发送调用保守占用完整预留，不假定零费用。只有有效用量和对应价格都存在时记录 USD 估算，价格保留调用时快照。

每次 HTTP 尝试单独预留与记录。租户行锁串行化短准入/结算事务，网络请求在锁外执行；预留主键提供幂等结算，数据库约束拒绝跨租户关联和错误 run actor。过期预留发送前再次验证，扫描器在锁内读取发送状态，避免释放与发送竞争。代价是同租户的准入短事务串行，规模扩大后需在保持原子性的前提下评估独立用量账本/计数方案。

上下文优先保留当前问题和本轮证据，历史按完整问答对裁剪。历史来源必须仍可读且仍为当前发布构建；旧引用编号不进入本轮 Prompt。新证据编号与持久化引用保持相同顺序，历史接口和流式接口使用一致排名。

验证包括 SQLite、真实 PostgreSQL、两个并发竞争场景、受控 HTTP socket、取消/断流、超时、401/429、未知用量和浏览器额度操作。受控服务是协议替身，不能用这些结果宣称真实模型质量或账单准确性；真实服务接入需要另行冻结模型/profile 并保存探测与效果记录。
