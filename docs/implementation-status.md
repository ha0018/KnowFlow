# 实现范围与后续验收

本项目根据技术方案构建，交付的是可运行开发基线。技术方案中的八周目标不是此次交付的测试结论。

| 领域 | 当前交付 | 未完成/待验收 |
| --- | --- | --- |
| 身份/权限 | 单租户账号、JWT、角色、KB/文档 ACL、数据库关联隔离 | 组织树、SSO、RLS；成员/授权管理主要通过 API |
| 文档 | 四种格式、版本、任务、租约/fencing、发布、软删除 | 批量上传、HTML/XLSX、OCR、解析沙箱、后台孤儿文件回收/物理清理 |
| 检索 | SQLite/PG 精确 cosine、中文 FTS/RRF、可选规则/模型改写与词项/远程重排、可选 HNSW 及规模诊断 | 真实语义模型校准、代表性负载与 ANN 效果门槛、BM25 对照 |
| 问答 | 引用、流式、取消、撤权隐藏、幂等、预算内的授权历史重放、独立模型配置与探测、原子额度预留/结算、调用价格快照 | 真实供应商闭环与质量/时延实测、供应商 tokenizer 校准 |

| 性能 | 未声明业务延迟/质量指标 | 技术方案 A01–A15 的完整安全矩阵、压力测试、故障演练和实测报告 |

2026-11-13 已交付 [S4 受控 Agent](controlled-agent.md)。SQLite/PostgreSQL 各 139 通过、2 跳过，新增 50 项专项测试（包含 31 条非法 schema），三个工具通过实际子进程、浏览器及容器链路；[报告](benchmarks/controlled-agent-2026-11-13.md) 保留原始证据。规则演示与本地 HTTP 协议替身通过，真实供应商的规划效果尚未验收。

工具使用固定入口的独立子进程，超时或取消时先 kill/wait，再结算未完成预留与审计；它用于终止可信只读工具，不接受任意 Python、SQL、Shell 或 URL，也不是运行不可信代码的资源沙箱。本地文档解析器仍只限制文件/页数/解压体积/文本体积；生产环境的解析隔离、CPU/内存限制属于 S5。

待执行验收时应冻结真实模型、语料、硬件、并发与配置，保存原始结果。没有证据的性能和质量数字不能写成项目成果。
