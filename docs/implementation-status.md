S2 的代码与自动验收已完成，支持独立地址/密钥、限额、重试、超时、取消、未知用量记录和历史重放；[供应商接入验收](model-integration.md) 待真实配置。当前受控 HTTP 协议测试不代表真实供应商验证。

2026-11-13 已交付 [S4 受控 Agent](controlled-agent.md)。SQLite/PostgreSQL 各 139 通过、2 跳过，新增 50 项专项测试（包含 31 条非法 schema），三个工具通过实际子进程、浏览器及容器链路；[报告](benchmarks/controlled-agent-2026-11-13.md) 保留原始证据。规则演示与本地 HTTP 协议替身通过，真实供应商的规划效果尚未验收。

工具使用固定入口的独立子进程，超时或取消时先 kill/wait，再结算未完成预留与审计；它用于终止可信只读工具，不接受任意 Python、SQL、Shell 或 URL，也不是运行不可信代码的资源沙箱。S5 文档解析器已移至不继承应用凭据的独立进程，父进程控制墙钟/输出/取消，Linux 实际执行 CPU/地址空间限制；Windows 不宣称 Linux 资源限制已通过。

2026-11-13 的 [S5 报告](benchmarks/delivery-2026-11-13.md) 记录新环境启动、160 项授权、50/20 份文件、重复故障、93 原文件/35 表恢复、四个浏览器场景和实际录屏；[A01–A15](acceptance.md) 逐项标记通过、未通过和待验收。API/检索延迟未达标，真实语义/人工及外部服务指标仍开放，完整 P0/P1 验收未全部关闭。
