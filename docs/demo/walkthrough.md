# 演示流程与证据

使用本地自编演示语料，不使用真实企业资料。默认账号及初始化方法见 README。以下流程约 2–3 分钟，所有质量/延迟数字以已归档报告为准。

[实际浏览器录屏（约 2 分 24 秒，无配音）](product-walkthrough.webm) 使用恢复的 SQLite 副本，依次展示问答/引用、统计/快照、成员/资料权限、评测、监控和手机布局。脚本为 `frontend/scripts/record-demo.mjs`，在前后端启动后运行 `npm run demo:record`；KNOWFLOW_E2E_BASE_URL 可指定独立验收地址。录制不是人工质量打分或公网部署证明。

| 时间 | 操作 | 展示重点 |
| --- | --- | --- |
| 0:00–0:27 | 登录星河科技，打开知识空间与退款政策 | 多租户、当前资料范围、版本和任务状态 |
| 0:27–0:54 | 提问“退款超过30天还能申请吗？”，点击引用 | 摘录演示、有依据回答、版本及原文位置 |
| 0:54–1:26 | 打开只读工具，执行业务统计并查看来源 | 规则规划、预算、实际工具轨迹与统计快照 |
| 1:26–1:51 | 管理员打开成员/角色与资料权限 | 管理入口与知识库授权范围；录屏不修改权限 |
| 1:51–2:13 | 打开检索评测及调用记录 | 固定分集、待人工复核、实际用量来源 |
| 2:13–2:24 | 查看手机布局 | 窄屏导航与业务卡片 |
